Database Management System (DBMS) — Chapter Summary

Concepts, Relational Model, Keys, SQL Commands & 1-Mark Objective Revision.

DBMS Definition: A software system designed to store, retrieve, manage, and manipulate structured data efficiently while preventing data redundancy and ensuring data integrity.

1. Key Database Terminology

  • Data vs Information: Data is raw facts; Information is processed meaningful data.
  • Table / Relation: Collection of data stored in rows (tuples) and columns (attributes).
  • Tuple (Row): Single record in a table containing specific attribute values.
  • Attribute (Column): Named field in a table representing a data property.
  • Degree: Total number of attributes (columns) in a table.
  • Cardinality: Total number of tuples (rows) in a table.

2. Types of Keys in Relational Database

  • Primary Key: Unique attribute that uniquely identifies each tuple in a table (cannot be NULL).
  • Candidate Key: Minimal set of attributes that can act as a primary key.
  • Alternate Key: Candidate keys that are not selected as the primary key.
  • Foreign Key: Non-key attribute in a table that references the primary key of another table.

3. SQL Commands Classification

  • DDL (Data Definition Language): Defines database structure — CREATE, ALTER, DROP.
  • DML (Data Manipulation Language): Manages data within tables — INSERT, UPDATE, DELETE, SELECT.
  • DCL (Data Control Language): Manages permissions — GRANT, REVOKE.
